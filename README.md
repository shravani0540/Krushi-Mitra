# Krushi Mitra

Krushi Mitra is a Django-based web application designed to help farmers access agricultural information and resources.

## Features

- Crop Information
- Market Price Updates
- Government Schemes
- Expert Guidance
- Farmer Training
- Agricultural News

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS

## Installation

1. Clone repository

git clone https://github.com/yourusername/Krushi-Mitra.git

2. Install Django

pip install django

3. Run migrations

python manage.py migrate

4. Start server

python manage.py runserver
